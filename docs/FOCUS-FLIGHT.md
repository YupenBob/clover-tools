# 专注航班

入口：/tools/fun/focus-flight/。提供简体、繁体、英文、韩文和日文。

## 使用体验

- 候机大厅选择六条亚洲航线、任务和 1–180 整数分钟，领取 Clover航空 SVG 纸质登机牌。航班、签发日期、登机时间、舱位、座位和序号按紧凑印刷布局呈现，主副票的 Code 128 条码由票面信息实际编码。桌面向外撕右侧副票，手机向下撕底部副票；单击或 Enter／Space 也呈现分离过程。
- 齿孔随拖动进度断开，纸张翘起、阴影和毛边变化；未撕完松手、取消或失焦会复位。完整撕下才创建会话并开始计时，主票盖上登机章，副票离开后进入沉浸客舱。
- 舷窗、机翼、云层、窗框与票面均为原创 SVG，采用渐变、滤镜和分层动画。晴空、日落、夜航分别调整光线；页面没有生成图片或位图背景。
- 起飞阶段最多 6 秒，短航程为总时长的 8%；巡航平稳，最后 6%／最多 45 秒进入下降。过场包含在用户选定的时长内，可直接巡航；暂停冻结有效进度。
- 舷窗与真实地理航图可以切换，航图提供全程和跟随镜头。进入飞行后表单收起，控件闲置后减弱；指针、触摸和键盘操作唤回，键盘聚焦的控件始终清楚可见。
- 客舱声默认关闭。发动机与气流独立混合，纸张撕裂声跟随手势，登机与抵达音克制；落地提示可单独选择。所有声音在浏览器本地合成，循环边界交叉混合，阶段间平滑改变响度和频谱。
- 抵达展示保留撕口的主票、登机章与抵达章，保存 1080 × 900 PNG；卡片包含真实航线、任务和时间。完整倒计时完成才进入最近 20 条日志，提前结束需要确认。
- 自动沉浸与原生全屏独立；按钮或 Esc 退出沉浸。Esc 先关闭当前弹窗或混音面板，退出后恢复滚动位置与焦点。手机横屏和短屏票面可滚动。

## 地理与资源

Natural Earth 1:10m 海岸线、湖泊和自然地形区域经过地理裁剪与保留拓扑的简化，转成 SVG 路径。投影为横纵等比例 Mercator；机场经纬度来自 OurAirports，大圆插值决定位置与朝向。地形区域纹理表达自然地理，未宣称测量高程、真实天气、航空公司航迹或实时航班。

静态地理 SVG 与航线、机场和飞机 SVG 分层：地理层通过 CSS 位移合成镜头，动态层独立更新 viewBox 和进度，不因飞机移动重绘全部海岸线。两层采用同一投影和镜头参数，浏览器回归核对机场在屏幕上的位置误差。

六条航线是 PVG—HND、PEK—ICN、TPE—HKG、HKG—SIN、TFU—BKK、HND—CTS。专注时长独立于航线公里数与实际飞行时间。

处理脚本 `scripts/prepare-flight-geography.py` 只在维护时运行，需要 Shapely；浏览器和 CI 无此依赖。将 land.geojson、lakes.geojson、regions.geojson 和 airports.csv 放入源目录，运行脚本生成 `src/lib/flight-geography.json`。源 URL、许可、原文件哈希、投影与派生文件哈希见 `public/focus-flight/geography.json`。两组数据均为公共领域，页面保留来源标注。访客只接收约 231 KB 的简化矢量路径，不下载原始数据库。

## 计时和恢复

`src/lib/focus-flight.ts` 保留 v1 状态与存储格式。运行时依据绝对截止时间，回调只更新显示；后台延迟和关页期间不会累计误差。暂停保存剩余毫秒，恢复重新计算截止时间，落地时间取截止时间。

同源不同语言页、不同标签页同步当前航程，完成记录按 ID 去重。支持 Web Locks 的浏览器串行处理登机提交，并检查已有航程；没有该 API 时仍检查本地活动会话。清空日志同时清除已落地活动状态，避免刷新重新记账；进行中的航程不受影响。

光线、镜头、混音和提示音选项以独立 v2 偏好键保存，恢复页面始终保持环境声关闭。计时恢复直接进入当前阶段，不重播撕票。存储被拒绝时当前页继续计时并提示无法恢复；声音、全屏或屏幕唤醒失败不影响航程。减少动态保留副票分离与盖章，取消持续运动。

设备休眠或关闭页面期间未暂停的计时继续。手动修改系统时间会影响计时；工具记录倒计时完成，不判断实际专注，也不限制其他应用。关闭或冻结页面期间不能保证播放提示音。日志摘要基于最近 20 条记录，今日按设备本地日期计算。任务、航程与日志不上传。

## 维护与检查

场景分别位于 FocusFlight.astro、FlightCabin.astro、FlightMap.astro、FlightTicket.astro、FlightPaper.astro。计时控制、撕票和声音分别位于 focus-flight.ts、flight/tear.ts 与 flight/audio.ts。纯地理与阶段算法位于 flight-experience.ts。交互文案按语言服务器输出。

`npm run check:all` 覆盖类型、单元、构建、内容、链接、SEO 与图标。飞行纯函数检查包含时长、后台截止时间、多次暂停恢复、无效存储、去重、Mercator 比例、机场距离、大圆跨日期线、同点与对跖点、阶段和撕票阈值。

`npm run check:browser` 包含 21 项飞行场景：五语计时、恢复、日志、PNG 下载、手机深色和声音、沉浸与提前结束，另有桌面拖动、真实触摸向下撕票、未完成回弹、pointercancel、失焦、键盘、减少动态、完整飞行阶段、镜头切换和并发登机。正式域名验收使用同一组交互并核对提交、五语页面、资产哈希、地理来源、搜索与 sitemap。

自动检查之外，实际审看桌面／手机 SVG 画面、六条航线、过程录像和导出卡片。视觉证据及性能测量保存在忽略的 output/focus-flight/svg 目录；声音以实际浏览器录制样例检查波形、响度和循环边界。发布证据见 QUALITY.md。
