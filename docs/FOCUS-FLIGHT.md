# 专注航班

入口：`/tools/fun/focus-flight/`。提供简体、繁体、英文、韩文和日文。

## 使用体验

- 原创地区示意地图与登机牌，飞机随专注进度沿曲线前进；浅色用纸张和浅绿地图，深色用夜航色调。
- 六条城市航线：上海—东京、北京—首尔、台北—香港、香港—新加坡、成都—曼谷、东京—札幌。时长预设是专注建议，不是航空时刻表。
- 1–180 整数分钟，可填写一件要完成的事；暂停后续航，暂停期间不消耗专注时间。
- 机舱白噪音和落地提示音分别选择、默认关闭，音量可调，声音在浏览器本地合成。切到沉浸视图后可用按钮或 Esc 退出，弹窗打开时 Esc 先关闭弹窗。
- 结束后生成 1080 × 900 PNG 落地纪念卡；完整倒计时完成才进入日志，提前结束会提示确认。
- 手机优先显示地图和登机牌，可直接在登机牌中选择航线；全部路线卡放在操作之后。

## 计时和恢复

`src/lib/focus-flight.ts` 是纯状态逻辑。运行状态保存截止时间，回调只负责显示；标签页回调延迟不会累计误差。暂停保存剩余毫秒，恢复重新计算截止时间。落地时间取截止时间，而不是延迟回调执行的时刻。

当前航程与最近 20 条完成记录存入版本化的 localStorage 键。刷新和重新打开会恢复，同源不同语言页或不同标签页同步当前航程，完成记录按航程 ID 去重。清空日志不会取消进行中的航程，已落地航程的保存状态会同时清除，避免刷新后重新出现已清空记录。

设备休眠或关页期间未暂停的计时继续；返回页面会校准。计时依赖系统时钟，手动改动设备时间会影响进度。本工具记录计时完成，不判断实际专注，不限制其他应用。落地提示音不能保证在浏览器冻结、设备休眠或页面关闭期间播放。

## 数据与兼容性

任务、航程和日志不上传，不依赖地图、音频或计时服务。清理站点数据、退出无痕浏览或更换设备会失去本地记录。存储被禁用时保留当前页计时并明确提示无法恢复；音频不可用时继续计时。支持的浏览器在运行中尝试保持屏幕唤醒，拒绝授权或不支持不影响计时。

日志和摘要仅基于最近 20 条记录，今日按设备本地日期计算。纪念卡包含任务文字，导出前可自行检查。地图为原创简化图形，仅营造氛围，不用于地理或航空导航。

## 维护与检查

主要文件是 `src/components/FocusFlight.astro`、`src/styles/focus-flight.css`、`src/scripts/focus-flight.ts` 和两个 `src/lib/focus-flight*.ts`。交互文案按语言服务器输出，客户端不加载全套翻译词库。

`npm run check:all` 覆盖类型、纯函数、构建、内容、链接、SEO 和图标。`npm run check:browser` 包含五语计时、暂停、落地、日志、真实 PNG 下载、手机、深色、音频、沉浸、提前结束、跨语言恢复、多标签同步及故障降级。生产部署检查同时验证新工具五语路由、发布资产、搜索索引、sitemap 和真实浏览器操作。
