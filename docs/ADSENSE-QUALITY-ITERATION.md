# 第二轮：先证明用户能得到什么

2026-10-16。此次截图明确显示 AdSense 拒绝理由为 **Low value content**。这是当前已知的审核分类；Google 没有提供具体问题 URL、评分或单一触发原因。第一轮技术整改完成，不等于内容价值已经通过审核。

## 当前判断

| 维度 | 已知事实 | 能支持的判断 |
| --- | --- | --- |
| 功能可靠性 | 已有工具测试和生产验收记录 | 可以说明已覆盖的操作能正常完成，不能证明用户需求、独特性或广告资格 |
| 内容准确性 | JSON 转表格旧指南提到单个对象、展开嵌套字段和 Excel 文件，与当前工具支持范围不符 | 存在应直接修正的质量问题；不能宣称这就是 Google 拒绝的全部原因 |
| 价值展示 | 首页主要展示工具集合；说明有输入输出示例，但缺少便于下载、核对、再操作的完整产出 | 值得先用少量实作案例改进，避免继续以文章数量代替用户价值 |
| 实际需求 | 站长确认 Cloudflare Web Analytics 已有该站点及访问数据；本次尚未取得具体数值 | 不能断言没有访问、没有统计，也不能把所选案例称为热门工具 |
| 抓取 | 上轮生产验收确认 Bot Fight Mode 关闭 | 只说明当时该设置状态，不能代替 Googlebot 日志或解释此次低价值判定 |

核心目标是让用户看到适用场景、完成操作、取得可用结果，并理解限制。SEO 用来帮助发现和理解这些页面，不能单独解决价值不足。

## 本轮具体改动

保留现有 76 个工具与导航结构，先做三个可以独立核对的演示案例，不把它们宣传为客户成功案例或访问量证明：

1. **四叶草拼豆图纸**：32×32 原创透明源图、实际编号图纸、逐色 CSV。核对 4 色合计 512 颗，说明图内编号与品牌商品色号的区别。
2. **可复现头像**：固定 Clover 种子、机器人画风与配色，提供实际 512×512 PNG 和 SVG。说明必须保留整套设置，以及版本更新可能影响结果。
3. **嵌套 JSON 转 CSV**：两条自建订单演示记录，保留前导零、嵌套对象、缺失值、中文和逗号。提供输入与实际输出，支持从案例入口载入固定样例；五种语言使用同一份样例。

案例入口接到简体首页、相关工具页和页脚。案例仅有简体正文，路由和语言切换明确按此处理，不生成不存在的翻译地址。页面提供 canonical、描述、面包屑及文章结构化数据，进入现有 sitemap 检查；页面不投放广告。

同步重写 CSV 指南，明确非空对象数组、嵌套值序列化、不导出 XLSX、Excel 文本列导入与公式风险。指南索引从真实文章更新时间计算“最新内容更新”，不再用固定旧日期和笼统“已校对”描述全部文章。

实际产出位于 `public/examples/`。`manifest.json` 记录生成时间、工具版本、参数、用量及文件哈希，便于维护者检查。再次生成时先构建并启动本地预览，再执行：

```bash
TEST_BASE_URL=http://127.0.0.1:4339 node scripts/capture-use-cases.mjs
```

这一步会替换案例文件，须检查新结果并重新构建；不能仅更新日期来冒充内容改进。图片字体可能随操作系统变化，跨环境核对图纸用量与尺寸，不要求 PNG 每个字节一致。

## 用访问数据决定下一批工作

需要同一时间范围（优先最近 28 天，不足则记录实际范围）的访问量、前 10 页面和来源。先确认是 Web Analytics 的页面访问数据，避免把 HTTP 请求数、静态资源和机器人访问当成用户数。

- 根据热门工具与来源确定最值得投入的 3–5 个任务，不按个人偏好直接重做全站定位。
- 对这些任务记录进入页面、实际操作、取得结果和遇到的问题。Web Analytics 的访问量不能直接证明导出成功、回访或任务完成；如需事件统计，另行确定最小事件与隐私披露，不能假定后台已有。
- 对有明确问题的工具优先改功能；对操作可完成但目的不清楚的工具改案例、提示与输出。每次改动记录具体解决的问题。
- Search Console 用于查看搜索词、收录和抓取；这些指标与 AdSense 审核是不同系统，不能相互替代。

## 下一次申请前

先核对案例是否仍可复现、核心页面是否准确、重点工具能否完成实际任务、站点信息是否真实，以及后台是否还存在其他审核问题。完成有实质作用的改动后再申请复审，保存提交时间和返回信息。

不设置自创的最低字数、文章数、日访问量或固定等待天数；不承诺通过。三个演示案例也不能单独证明“低价值内容”已经解决。是否继续聚焦某类用户，应由实际使用与反馈支持。

依据：[AdSense 站点准备说明](https://support.google.com/adsense/answer/12176698)、[Google 发布商政策](https://support.google.com/adsense/answer/10502938)、[以用户为先的实用内容](https://developers.google.com/search/docs/fundamentals/creating-helpful-content)。最后一项是搜索质量建议，不是 AdSense 内部评分公式。
