# FPS练枪：使用、模型与验证

更新：2026-10-01。配置版本：`2026-10-01.1`。

## 使用范围

入口：`/tools/fun/fps-aim-trainer/`，以及 `/en/`、`/zh-hant/`、`/ko/`、`/ja/` 对应页面。五语页面共用 `FpsTrainer.astro` 与同一训练实现；搜索、关联工具、主题和收录沿用站点约定。

面向 CS2 与瓦洛兰特玩家，提供 AK-47、M4A1-S、Vandal、Phantom 四把步枪，以及以下训练。地图和枪械示意模型为原创几何体，不使用原游戏地图或美术资源。

| 项目 | 操作与反馈 |
| --- | --- |
| 点射微调 | 随机头部靶；首发目标命中率、首次有效命中用时、爆头率 |
| 横移急停 | A/D 移动，松键或反向输入减速；移动中开枪比例、进入准确速度范围后的击发间隔 |
| 掩体预瞄 | 从掩体两侧探出；首次可见时准星偏差、首发目标命中率 |
| 短连发与压枪 | 连发固定靶；命中率、弹着角度分布、平均击发时后坐力偏移 |
| 移动跟枪 | 持续横移靶；头部瞄准时间占比、射击命中率 |
| 多目标切换 | 完成目标后处理其他靶；完成到下一目标首次命中的间隔、首发命中率 |
| 自由热身 | 自由移动和射击，用户主动结束；按实际训练时间统计 |

默认 60 秒；当前配置允许 15–180 秒、5–40 米、1–8 个目标、0.5–4 m/s。固定数量的模式会禁用数量设置，静止模式禁用目标速度，自由热身禁用倒计时。压枪与跟枪靶承受致命伤害后直接恢复生命，保持可见，避免练习被重生空窗打断。

点击进入靶场只加载并准备画面，不锁定鼠标、不计时；在准备面板点击“开始并锁定鼠标”后才开始。中央固定准星，鼠标转向，WASD 移动，Shift 慢走，Ctrl 蹲伏，左键射击，R 换弹；瓦洛兰特步枪右键开镜。Esc 解锁并暂停，暂停面板提供全屏、恢复与结束。失焦、标签页隐藏、鼠标锁定丢失或渲染出现较长停顿都会暂停，恢复必须主动点击。自动暂停不强制聚焦任何控件；切出页面或退出会取消正在等待的锁定请求，浏览器迟到的授权会立即释放，返回页面不会自动重新锁定。画面停顿单独提示尝试流畅画质。手机显示设置和使用电脑键鼠的提示。

渲染停顿的暂停阈值由 `FPS_CONFIG.simulation.maxFrameGap` 配置，当前为 1 秒；首轮回归发现原先 250 毫秒阈值容易让短暂掉帧打断训练，因此已放宽。失焦、隐藏和 Esc 不依赖此阈值，仍即时暂停。

## 灵敏度校准

1. 选择游戏、枪械，填写游戏灵敏度与鼠标 DPI；参考水平 FOV 分别按 CS2 的 4:3 和瓦洛兰特的 16:9 定义，可选择原生比例、4:3 黑边或拉伸。
2. 可先在原游戏实际测量转一圈的鼠标移动距离，填入 cm/360。设置为 0 时使用游戏灵敏度转换。
3. 点击校准，等待准备完成，再点击开始锁定鼠标。沿同一水平方向移动鼠标 `FPS_CONFIG.calibration.distanceCm`（当前 10 cm），左键确认，Esc 取消。系统记录浏览器返回的位移总量；不足或超出支持范围的校准会被拒绝。
4. 修改游戏、灵敏度、DPI 或 cm/360 会清除校准值；更换设备、浏览器或系统鼠标加速设置后也应重新校准。

角度增益优先级：已校准值 → cm/360 与 DPI 换算 → 游戏 yaw 系数 × 灵敏度。换算为 `360 × 2.54 / (DPI × cm/360)` 度/计数。FOV 使用 `2 × atan(tan(horizontal/2) / referenceAspect)` 转换为垂直视野，拉伸比例只改变呈现。

优先请求 `unadjustedMovement`，不支持时回退普通 Pointer Lock，并显示重新校准提示。浏览器能接受请求不等于设备输出已经通过原游戏测量。兼容性与用户手势要求见 [MDN Pointer Lock](https://developer.mozilla.org/en-US/docs/Web/API/Pointer_Lock_API)。

部分 Chromium 版本在原生 Esc 退出锁定后有约 1.25 秒的重新锁定等待窗口。过早点击恢复时保持暂停并提示稍候再次点击，重复未完成请求会被忽略；不自动恢复。依据 [Chromium 实现](https://github.com/chromium/chromium/blob/main/chrome/browser/ui/exclusive_access/pointer_lock_controller.cc)。浏览器测试在 `config/quality.mjs` 配置原生退出后的等待时间，并等待实际锁定状态，游戏物理和计时规则保持独立。

## 模块职责与扩展

| 位置 | 职责 |
| --- | --- |
| `config/fps.mjs` | 默认值、范围、按键、游戏/枪械规则、模式策略、场景、画质、历史容量与证据状态 |
| `config/fps-sources.mjs` | 固定来源版本、字段与刷新地址 |
| `config/fps-data.mjs` | 已提交的精简参数快照与原始输入 SHA-256；构建和训练不联网刷新 |
| `src/scripts/fps/types.ts` | `GameProfile`、`WeaponProfile`、`TrainingMode`、`SessionResult` 及输入/射击事件契约 |
| `math.ts` | 灵敏度、FOV、确定性随机、射线/包围盒/球体相交等纯计算 |
| `core.ts` | 固定步长时钟、移动、散布、射击、换弹、后坐力、遮挡与部位伤害 |
| `statistics.ts` | 观察模拟事件，累计成绩、时间覆盖率与有界图表数据，不改变物理状态 |
| `modes.ts` | 模式注册表与目标生成策略，不依赖 Three.js |
| `renderer.ts` | Three.js 场景、相机和弹着显示；读取训练状态，不决定命中 |
| `controller.ts` | 带时间戳的键鼠输入、鼠标锁定、暂停、全屏、校准和资源生命周期 |
| `pointer.ts` | 显式鼠标锁定请求、原始输入降级、取消与迟到授权处理；不操作焦点或训练计时 |
| `report.ts` | 指标、弹着图、时间线、参数来源与可比较历史的安全 DOM 展示 |
| `storage.ts` | 设置规范化、历史验证、容量和存储失败降级 |
| `src/lib/fps-i18n.ts` | 共享界面五语文案与工具元信息；繁体从简体转换 |
| `FpsTrainer.astro` / 五个路由页面 | 配置驱动表单与薄路由，沿用 ToolLayout |

Three.js 锁定为 `0.186.1`（类型 `0.186.0`）。控制器仅在进入靶场或校准时动态导入渲染器；设置页不会请求 Three.js 渲染包。当前渲染需要 WebGL 2。离开时取消动画帧、解除锁定、退出全屏、断开监听与尺寸观察器并释放 GPU 资源；图形上下文丢失时暂停并要求结束后重新进入。

增加枪械：在配置增加预设、单位与证据，添加固定数据字段，验证规则即可，不修改渲染核心。增加模式：登记 `TRAINING_MODES`，复用或新增 `modes.ts` 的生成行为，补充五语名称/说明和相应测试。超出现有生成策略的新玩法需扩展模式契约；渲染器仍只接收状态。修改模型、默认值或参数来源时更新 `revision`，防止旧成绩混比。

简体薄路由标记 `@shared-tool-ui`，现有繁体生成和批量页面翻译脚本会跳过这类页面，避免覆盖共享组件导入。增加语言时维护对应薄路由和共享词典，再执行搜索生成与完整构建检查。

## 参数来源与还原状态

每个游戏和枪械字段均有 `unit`、`source`、`field`、`version` 和 `status`，页面可查看。状态：`source` 来源已核验；`measured` 原游戏测量已验证；`approximate` 近似模拟。**当前没有任何字段标记为原游戏测量已验证。** 原始配置中的数值与使用这些数值重建的算法是两种证据。

### CS2

采用 [SteamTracking 原始武器配置镜像](https://github.com/SteamTracking/GameTracking-CS2/blob/ce2a2deb0cba2f7e8443901690c0abdb5191b7ab/game/csgo/pak01_dir/scripts/weapons.vdata) 与同提交的 [convars](https://github.com/SteamTracking/GameTracking-CS2/blob/ce2a2deb0cba2f7e8443901690c0abdb5191b7ab/DumpSource2/convars.txt)。提交固定为 `ce2a2deb0cba2f7e8443901690c0abdb5191b7ab`，版本标识 `2000919`。

| 字段 | 使用方式与状态 |
| --- | --- |
| `m_flCycleTime` / `m_iMaxClip1` | 射击间隔秒数与弹匣容量，来源核验 |
| `m_nDamage` / `m_flHeadshotMultiplier` / `m_flArmorRatio` / `m_flRangeModifier` | 基础伤害、头部倍数、护甲比例、距离衰减数值，来源核验；护甲和伤害结算算法近似 |
| `m_flSpread` / `m_flInaccuracyStand` / `m_flInaccuracyCrouch` / `m_flInaccuracyMove` | 原始散布数值，来源核验；采样分布与连续射击叠加算法近似 |
| `m_flMaxSpeed` / `m_yaw` / `m_pitch` | 速度和灵敏度原值，来源核验；Source 单位转米的系数仍为近似假设 |
| `sv_accelerate` / `sv_friction` / `sv_stopspeed` | 移动模型的来源参数；完整减速、碰撞和准确性恢复模型未做原游戏对照 |
| `m_flRecoveryTimeStand` | 恢复时间数值来源核验；本工具指数恢复曲线近似 |
| `m_flDisallowAttackAfterReloadStartDuration` | 用作换弹攻击锁定时间，标记近似；不能解释为已测量完整换弹动画 |
| 后坐力、停稳阈值、视野默认值、蹲/走倍率、眼高 | 可配置近似模型 |

CS2 使用确定性水平后坐力曲线，瓦洛兰特使用超过连发阈值后的随机水平偏移，均没有重现原游戏完整后坐力算法。镜像中 recoil seed 被保留以便未来替换，但当前模型不以它宣称还原。

### 瓦洛兰特

采用 [Valorant-API 武器快照](https://valorant-api.com/v1/weapons?language=en-US)，对应 [版本端点](https://valorant-api.com/v1/version) 的 `13.06.00.5590001`。仓库保存精简结果与 SHA-256，后续训练不会请求该服务。[服务声明](https://valorant-api.com/) 明确其非官方且不受 Riot 背书。

射速、弹匣、换弹、基础首发精度、开镜倍率/射速/精度和伤害距离档位标记来源核验。官方 [武器库](https://playvalorant.com/en-us/arsenal/) 用于交叉确认枪械类别，[9.10 更新](https://playvalorant.com/en-us/news/game-updates/valorant-patch-notes-9-10/) 确认 Phantom 的 0–20 米 39 躯干伤害及 20 米以上 35 伤害档位；[13.06 更新](https://playvalorant.com/en-gb/news/game-updates/valorant-patch-notes-13-06/) 用于版本背景核对。官方交叉核验没有覆盖社区快照每个字段。

移动、减速、灵敏度系数、散布采样、蹲伏收益、后坐力与恢复采用明确标记的近似模型。跑动散布以 9.10 更新中的步枪跑动误差 6 为参考，角度映射和分布仍标记近似。这里的目标生命值是训练设定，不模拟护盾种类、穿墙、受击减速或技能状态。

### 刷新数据

在审核版本和官方变更后修改 `fps-sources.mjs`，执行：

```bash
node scripts/import-fps-data.mjs
```

导入器检查字段完整性、有限数值和瓦洛兰特版本，并在读取前后核对同一版本；版本不符会失败。需要代理或离线输入时，可设置 `FPS_DATA_INPUT_DIR`，其中包含 UTF-8 的 `cs2-weapons.txt`、`cs2-convars.txt`、`val-weapons.json`、`val-version.json` 四个原始响应。不能用本地文件绕过版本审核；重新导入后应检查快照差异、证据和配置版本并重跑测试。

## 时钟、判定与统计分母

模拟步长为 `1/240` 秒，输入携带本轮有效训练时间，输入处理前推进模拟，渲染帧率不推进独立物理变量。射击事件保持枪械间隔；运动状态采用固定步长离散计算，判定精度受约 4.17 ms 步长限制。暂停不累计训练用时。

急停根据真实模拟速度与 `maxSpeed × stopRatio` 判定，反向输入参与物理减速，不直接置零。射线先检查掩体，再寻找最近的头部球体、躯干与腿部包围盒；不会穿过掩体计命中。靶体尺寸、护甲假设和阈值都是训练模型。

| 指标 | 定义 |
| --- | --- |
| 命中率 | 命中发数 / 射击发数；身体与腿部命中也算命中 |
| 爆头率 | 头部命中发数 / 全部命中发数 |
| 首发目标命中率 | 各目标首次尝试的有效命中次数 / 首次尝试次数；头部专用模式要求命中头部 |
| 首次命中用时 | 目标首次可见到首次有效命中的平均间隔，不是最终击杀时间 |
| 移动中开枪比例 | 击发时速度超过准确性阈值的发数 / 全部发数 |
| 停稳后击发间隔 | 速度进入准确范围后到击发的平均间隔；从未发生减速转换的射击不参与 |
| 预瞄偏差 | 目标第一次可见时，目标头部中心与准星的角度距离 |
| 跟枪覆盖率 | 准星射线落在无遮挡头部区域的累计时间 / 有效训练时间，按时间累加 |
| 切换间隔 | 完成一个目标，到首次有效命中另一目标的平均间隔 |
| 后坐力偏移 | 每次击发前的模拟水平/垂直后坐力向量长度的平均值，单位度 |

零分母显示 `—`，全部未命中显示 0% 命中率和 `—` 爆头率。提前退出保留实际时间并标记提前结束，不进入已完成最佳成绩比较。弹着图相对射击时最近目标的头部中心，超范围点钳制到图表边缘；时间线展示移动、松键、进入准确速度范围与击发事件。

## 本地存储与隐私

设置键 `ct-fps-prefs`，成绩键 `ct-fps-history`，默认保留最近 80 次。设置与校准、成绩分别可清除。存储读取、解析、写入和清除均捕获异常；禁用存储时仍能训练，页面提示无法保存。

完整统计计数不采样。本轮图表保留最多 1500 个弹着点和最近 120 个时间线事件；持久化每条成绩均匀采样最多 64 个弹着点，保留最近 40 个时间线事件，以控制存储容量。容量均在配置维护，浏览器仍可能因全站配额或隐私模式拒绝写入。当前历史列表展示统计比较，不提供旧报告重放。

比较键包含配置版本、游戏、枪械、模式及影响训练的全部设置，排除音效与画质。只比较已完成且有射击数据的同配置记录。训练输入和成绩不上传；站点已有统计/广告行为仍按站点隐私说明处理。

当前验收基于本机 Edge；远程 Chromium CI 与部署状态在交付时单独确认。没有原游戏运动轨迹、完整后坐力或玩家效果对照证据，因此保留近似标记，不把训练成绩转换为游戏段位，也不承诺实战提升。

鼠标专项回归另施加低于阈值的 0.5 秒阻塞与高于阈值的 1.2 秒阻塞：前者保持训练与锁定，后者解锁暂停并提示画面停顿。测试时长由当前配置阈值计算；修改阈值后自动随之调整。
