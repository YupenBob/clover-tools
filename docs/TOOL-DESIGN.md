# 工具页设计与布局

统一品牌、控件和交互约定，按工具任务组织画面。公共组件提供基础能力，不要求每个工具使用相同的卡片数量、内容顺序和侧栏。

## 页面框架

`ToolLayout` 保留导航、五语标题、SEO、推荐工具、广告位和使用说明。工具内容默认使用完整宽度，推荐工具放在操作区之后。页面内容最大宽度为 1280px，首页、指南和政策页沿用原宽度。

布局通过两个独立属性控制：

| 属性 | 可选值 | 用途 |
| --- | --- | --- |
| `layout` | `wide`（默认）、`sidebar` | 决定推荐工具的位置 |
| `workspace` | `flow`、`split`、`dashboard`、`canvas`、`inspector`、`preview` | 提供可选的操作区组合 |

`src/lib/tool-presentation.ts` 登记跨语言共用的默认组合。JSON、Base64、URL、Unicode、JSON/XML/YAML 和五种代码格式化工具用 `split`；时间戳用 `dashboard`，配色用 `canvas`，正则用 `inspector`，二维码、颜色转换和单位换算用 `preview`。其他工具用 `flow`，差异对比在 `flow` 内组合双输入与完整宽度的报告。

这些组合是默认值。页面可显式覆盖，也可以在 `flow` 内使用自己的网格、画布或组件，不必增加公共布局类型。

- `split`：桌面双栏输入与输出，窄屏按文档顺序堆叠。
- `dashboard`：顶部数据横跨两栏，转换区域并排。
- `canvas`：视觉结果在前，桌面设置区在旁，窄屏设置区在后。
- `inspector`：输入区占桌面左栏，实时高亮与报告在右栏；窄屏按输入、高亮、报告排列。
- `preview`：配置与结果并排，结果可用无卡片边框的画布或大数值展示；窄屏配置在前。
- 窄屏的二维码尺寸与容错级别、单位换算来源与目标保持成对排列，避免参数区占用过多高度。
- `flow`：按工具自己的内容顺序排列。

需要独立的标题表现时使用 `hero` 命名插槽，保留一个清晰的 `h1`。避免通过 CSS 重排改变视觉顺序而保留不同的键盘顺序。

## 面板与控件

`ToolPanel` 默认 `surface="card"`，也支持 `surface="plain"`、`description`、`actions` 和 `footer` 插槽。`headingId` 可供编辑器的 `aria-labelledby` 引用。可视化工具可直接使用画布，不必再套一层带边框的卡片。面板是可选基础组件，已有手写区域仍可使用。

金色保留在品牌、图标、选中和焦点上。工具主按钮使用高对比文字与背景；标题、描述、结果、说明有不同层级。输入框、复制和错误提示继续遵循全站交互约定。样式位于 `src/styles/tool-workspace.css` 和 `src/styles/daily-workspaces.css`，以 `.tool-page` 为边界；日常工具样式仅由使用它的页面加载。

## 日常工具的独立布局

计算器、计时器、BMI、理财、日期间隔和年龄计算使用 `flow`，由各自组件组织画面，不增加新的公共布局枚举，也不强制使用 `ToolPanel`。五语路由共用对应组件、`daily-tool-i18n.ts` 文案和计算内核。

- 计算器保持紧凑按键，旁边是本次访问的计算记录；手机按输入、记录的顺序堆叠。表达式采用有长度和递归上限的运算语法，支持括号、右结合幂、平方根、阶乘、百分比和科学计数法；不执行 JavaScript，兼容部署时的 CSP。Enter 保留原生按键的激活行为。
- 倒计时使用截止时间，回调只负责刷新；暂停保留剩余毫秒，重置回到配置时长。秒表用单调时钟，暂停与计次按动作发生的时刻采样。结束声音由用户选择，页面需保持打开。
- BMI 支持公制与英制、成人中国 / WHO 参考标准。刻度按实际数值连续移动，超出显示刻度时位置钳制，原始计算值仍显示。空值、越界值清除结果并禁用复制。
- 理财采用三个可用方向键切换的标签：等额本息、年复利、百分比。大数值与图表旁有文字明细；亏损与正向收益采用对应的图例。零利率和极小利率保持稳定；百分比总和为零时占比显示未定义。
- 日期间隔区分相差天数与包含起止日的日历天数。整月按原始日期锚定，月末无对应日时钳制，再计算剩余自然日。日期加减只接受整数，年份限定 0001–9999。
- 年龄允许指定截至日期，显示周岁、日历年龄、已出生天数与下一次生日。生日当天剩余零天；2 月 29 日在非闰年按 2 月 28 日计算。按年份计龄明示公历年份公式。

日历计算使用与时区无关的自然日序号，避免夏令时改变天数。输入无效时显示错误、移除旧结果并禁用复制。数值、日历和时钟边界有独立单元测试，六个页面均有五语浏览器回归。

## 新增趣味工具的独立布局

三个工具继续使用 `flow`，由对应组件提供自己的组合：拼豆采用图纸、设置与材料清单，手机上先展示设置；头像采用角色预览、六个示例与配色面板，手机设置区保留随滚动显示的即时缩略预览；人格测试在介绍、逐题答题与四维报告之间切换。均不增加公共布局枚举。

`src/styles/fun-workspaces.css` 仅由这些页面加载，`FunToolData` 只输出当前工具的本地化文案。五语路由共享对应组件和客户端脚本，计算规则在独立纯函数中维护。导出包含实际编号图纸、透明 PNG/SVG 或偏好分享卡片，打印只呈现图纸和材料图例。

专注航班使用 `flow` 和独立组合：真实地理 SVG 航图与候机表单并列，领取 Clover航空纸质登机牌后撕下副票，进入原创 SVG 舷窗客舱。三种光线、分层声音、全程／跟随镜头与盖章留票围绕同一航程组织；手机副票向下撕。沉浸模式让导航、配置与日志退出场景和键盘焦点范围。详见 [FOCUS-FLIGHT.md](FOCUS-FLIGHT.md)。

## 配色工具

五语路由共用 `PaletteGenerator.astro`，路由标记 `@shared-tool-ui`，批量翻译脚本会跳过。色相和方案改变即时更新；每个色块是原生按钮，可用 Enter 或空格复制。初次渲染和滑动不反复触发状态播报。

互补、邻近、三角、四色方案的五个色块来自对应色相与深浅变化，单色方案按明度递增，不再用无关色相补足数量。配色属于理论起点，不能据此认定文字与背景满足对比度要求。

## 交互与状态

二维码、颜色和单位换算的五语路由共用 `CodeGenerator.astro`、`ColorConverter.astro`、`UnitConverter.astro`。标签在 `visual-tool-i18n.ts`，单位名称和因子在 `unit-data.ts`，计算与状态控制在对应客户端脚本。

- 二维码内容或参数改变立即清除旧预览与下载；成功生成后才能导出 PNG。条形码同样经过实际图片转换后开放下载。异步结果只能提交到仍然对应的输入版本。
- 颜色支持短 HEX、RGB 和 HSL；超范围或不完整输入显示错误，并保留最后有效预览。色值可通过原生按钮复制，示例文字按相对亮度选择黑或白。
- 单位换算随输入更新，空值或非有限数值清除结果并禁用复制；结果保留 12 位有效数字，小数值不会因固定小数位数被显示为零。
- 文本工作台支持 Ctrl/Cmd + Enter。Unicode 非法码点作为输入错误展示；正则零宽匹配按 Unicode 码点推进；CSS 缩进、末尾声明、重复属性顺序、字符串与 `calc()` 空白有针对性回归。

## 验证

运行 `npm run build` 和 `npm run check:browser`。`check:tool-types` 已接入 `npm test`。浏览器回归包含五语 JSON、文本工作台、差异对比、正则、色板、时间戳、二维码与条形码实际 PNG 下载、颜色输入校验与单位精度，以及六个日常工具的运算、计时、日期和无效输入。新增 20 项趣味工具场景覆盖用量核对、图片解码竞争、PNG/SVG/CSV 下载、透明背景、打印样式、答题修改与访问结束清除，以及五语分类和搜索入口，并检查移动端和深色主题。

已有系统 Chromium 时可使用 `PLAYWRIGHT_EXECUTABLE_PATH=/usr/bin/chromium`；否则继续使用 `PLAYWRIGHT_CHANNEL` 或默认的 Playwright Chromium。测试截图保存在忽略目录 `output/playwright/`。
