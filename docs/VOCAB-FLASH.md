# 背单词速刷

生产地址：https://clovertools.cn/tools/daily/vocab-flash/

站内路径：`/tools/daily/vocab-flash/`（繁体：`/zh-hant/tools/daily/vocab-flash/`）

一个克制的翻卡背单词工具。目标是减少一轮复习的开始和结束成本：选书、定词数、看词、判断，结束后只把没认出来的词留下。

## 词书与数据

- 六本词书：中考核心、高考核心、四级核心、六级核心、托福核心、雅思核心。
- 每本 60 词，共 360 词；每词包含拼写、音标、词性、中文释义、英文例句与例句翻译。
- 词表按常见学习阶段和考试场景整理，是精选核心词，不宣称覆盖官方考纲或完整词表，也不代表官方词频顺序。
- 数据位于 `src/lib/vocab-books.ts`，界面逻辑位于 `src/lib/vocab-flash.ts` 与 `src/scripts/vocab-flash.ts`。

## 交互

1. 选择词书和本轮词数（20 / 40 / 全部）。
2. 开始后先显示单词与音标。轻点卡片、点击提示或按空格显示释义与例句。
3. 直接按“认识”或右方向键立即进入下一词；按“不认识”或左方向键时，如果释义尚未展开，会先展开释义，再由“下一个”继续。
4. 完成后显示正确率、用时、本轮认识/待复习数量，并列出本轮生词。可以只刷当前词书仍标记的错词。

键盘：`Space` 看释义，`←` 不认识，`→` 认识，`Enter` 继续，`Esc` 返回选书。手机上不显示键位提示，直接使用按钮。

## 选词与进度

普通轮次按“未学 → 错词 → 已掌握”的优先级抽取，同一轮不重复。指定词数不足时用已掌握词补齐；选择“全部”则整本进入本轮。

本地存储键：

- `clover-vocab-flash-progress-v1`：每本词书的 `known`、`wrong`、`today`、`todayCount`。
- `clover-vocab-flash-prefs-v1`：上次词书和本轮词数。

`known` 与 `wrong` 互斥。选择“认识”会移出错词并计入已掌握；选择“不认识”会移出已掌握并计入错词。“今日”按设备本地日期统计作答次数。无痕模式、清理站点数据或更换浏览器后进度无法恢复。

## 设计

- 暖白 / 深色自适应；正文使用系统无衬线，例句使用阅读衬线。
- 六本书封使用低饱和主色，色值只承担识别，不作为学习含义。
- 设置区使用书封、进度细线和分段控件；学习区收窄为单张卡片，弱化周边工具入口。
- 开始、答题和结果切换时滚动到任务区域；尊重 `prefers-reduced-motion`。
- 结果页使用环形正确率、三项指标和错词列表，不生成分享图片，不引入排行榜或游戏化奖励。

## 发音与隐私

发音使用浏览器 `SpeechSynthesisUtterance`（`en-US`），点击按钮才播放；声音、口音和可用性取决于系统与浏览器，部分实现可能需要联网。词书选择、进度与错词只写入当前浏览器的 localStorage，不上传，不需要注册。

## 验证

- `scripts/tests/vocab-flash.test.mjs` 覆盖六本词书完整性、词条唯一性、存储解析、认识/错词互斥、选词优先级、日期与时长格式。
- 浏览器实测 1440 桌面、390 / 320 手机宽度与浅色 / 深色主题；检查了开始、显示释义、不认识后继续、结果、错词复习、刷新后进度与词书偏好恢复。
- 新增页面进入构建、内容关联、链接、sitemap、SEO、发布商、emoji、图标与工具类型检查。简体页面可收录，繁体页面按现有工具收录策略生成但暂不进入 sitemap。
- 英 / 韩 / 日工具页需要另行翻译；当前本地化列表会过滤未翻译的新工具，避免出现指向不存在页面的链接。
