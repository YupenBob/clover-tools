# 图片转 ASCII（image-to-ascii）选题卡

## 用户与场景
把图片转成字符画，用于终端/社交/趣味；与 ascii-art（文字转艺术字）不同。

## 核心功能
1. 上传图片；字符集（经典/密集/自定义）、宽度、反色、亮度/对比度；实时预览。
2. 彩色 ANSI 开关（终端复制）；复制纯文本/下载 .txt；示例图。
3. 性能：大图降采样；移动端 360px；5 语言、深浅色、键盘。
4. 无外部资源；本地处理。

## 数据/文件/测试
`src/lib/image-to-ascii.ts` 像素→字符/行；`src/scripts/image-to-ascii.ts`；组件；5 薄路由；集成；单测（亮度映射/宽度/反色/空图）；浏览器用例（真实小图、复制/下载、参数变化、非法文件、360px、深色、CSP）；docs/IMAGE-TO-ASCII.md。SEO：图片转 ASCII、字符画、ASCII 艺术。
