# HTTP 状态码参考（http-status）选题卡

## 用户与场景
开发/排错时快速查状态码含义、常见原因、相关方法/头；现有 http-tester 是发请求，本工具是离线参考。

## 核心功能
1. 状态码列表（1xx–5xx）+ 搜索（数字/名称/关键词）；分类筛选。
2. 详情：含义、常见原因、处理建议、示例响应、相关头/方法、是否可缓存、是否重试（谨慎措辞）。
3. 常用方法/头速查（GET/POST/...、Content-Type/Cache-Control/ETag 等）。
4. 复制、深链（#404）、键盘搜索、5 语言、移动端、深浅色。
5. 数据静态可离线；不联网。

## 数据/文件/测试
`src/lib/http-status.ts` 数据 + 查询/分类；`src/scripts/http-status.ts` 交互；组件；5 薄路由；集成；单测（搜索/分类/未知码）；浏览器用例（5 语言、搜索、深链、复制、360px、深色）。docs/HTTP-STATUS.md。SEO：HTTP 状态码、404、500、状态码大全。
