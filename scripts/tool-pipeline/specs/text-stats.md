# 文本统计与可读性（text-stats）选题卡

## 用户与场景
写作者/运营统计字数、词数、句数、段落、阅读时间、重复词与可读性；与 text-toolbox（去重排序）不同。

## 核心功能
1. 粘贴/输入文本；实时统计：字符（含/不含空格）、汉字、英文词、句、段、行、阅读时间（可配置速度）。
2. 中英文分别处理；标点/数字/链接/代码块口径说明。
3. 重复词 Top 10（可选停用词）；可读性提示（句长/段长，非评分结论）。
4. 复制统计 JSON/文本；清空；5 语言、键盘、360px、深浅色；无网络。

## 数据/文件/测试
`src/lib/text-stats.ts` 纯函数；`src/lib/text-stats-i18n.ts`；`src/scripts/text-stats.ts`；组件；5 薄路由；集成；单测（中英/空/超长/标点/代码/停用词）；浏览器用例（实时统计、复制、清空、360px、深色、CSP）；docs/TEXT-STATS.md。隐私：文本不出本地。SEO：字数统计、阅读时间、文本统计。
