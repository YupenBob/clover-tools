# 色觉模拟器（color-blindness）选题卡

## 用户与场景
设计师检查配色在红色盲/绿色盲/蓝色盲下的可辨识度；与 wcag-contrast 互补。

## 核心功能
1. 上传图片或输入颜色；模拟三种色觉类型（矩阵变换）；原图/模拟并排或滑块。
2. 取色对比；显示模拟前后 HEX；下载模拟图。
3. 说明是近似模拟，不替代医学诊断。
4. 5 语言、键盘、360px、深浅色；无外部资源。

## 数据/文件/测试
`src/lib/color-blindness.ts` 矩阵/变换/取色；`src/scripts/color-blindness.ts`；组件；5 薄路由；集成；单测（矩阵/边界/非法颜色）；浏览器用例（上传/模拟/下载/非法/360px/深色/CSP）；docs/COLOR-BLINDNESS.md。SEO：色盲模拟、色觉检查、配色无障碍。
