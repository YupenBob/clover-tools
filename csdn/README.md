# CloverTools × CSDN 发布包

本目录是 CloverTools 的 CSDN 宣传物料，由 `scripts/build-csdn.mjs` 从 `data/articles.json` 自动生成，包含：

| 路径 | 内容 |
| --- | --- |
| `00-品牌宣传/` | 品牌宣传主文（先发这篇，建立品牌认知） |
| `01-SEO文章/` | 137 篇 SEO 文章（116 篇正文就绪，21 篇待补全），按工具分类存放 |
| `发布计划.csv` | 全部文章的元数据：标题、摘要、关键词、工具链接、优先级、建议发布日期、CSDN 标签 |

重新生成：`node scripts/build-csdn.mjs`（会清空并重建 `01-SEO文章/` 和 `发布计划.csv`，不会动 `00-品牌宣传/` 与本文档）。

## 一、发布节奏（建议）

排期原则：**品牌文先行，高频关键词优先，稳定频率更新**。

1. **第 1 篇**：发布 `00-品牌宣传/` 品牌主文，让读者先认识 CloverTools；
2. **随后按 `发布计划.csv` 的「建议发布日期」发布 P0 文章**（周一/三/五各一篇，约 3 篇/周），P0 共 83 篇，约 28 周发完；
3. **P1（33 篇）排在其后**，保持节奏即可；
4. **P2（21 篇）为待补全文章**，先补正文再排期，不要发空壳；
5. 如果时间充裕，可改为每天 1 篇，但建议同一账号每日不超过 2 篇，避免被判定为批量营销号。

发布时优先挑「搜索意图 = error-fix」的文章（报错排查类），这类关键词在 CSDN 站内搜索和百度上的流量更稳定。

## 二、发布操作清单（每篇）

1. 打开 CSDN 创作中心（https://editor.csdn.net/），选择「Markdown 编辑器」；
2. 粘贴对应 `.md` 文件全文，检查标题层级（`#` 标题会作为文章标题，粘贴后记得在编辑器标题栏再填一次）、代码块、表格是否正常渲染；
3. 设置信息：
   - **标题**：沿用文件内 `#` 标题（已含关键词），可微调但保留核心关键词；
   - **摘要/描述**：使用文件开头的 `> 引用` 行内容；
   - **标签**：使用 `发布计划.csv` 的「CSDN建议标签」列（3~5 个）；
   - **分类**：按主题选择，开发类选「开发工具 / 编程语言 / 数据库」等，生活类选「生活」相关栏目；
   - **原创声明**：勾选「原创」，文章等级选「优质」候选；
   - **封面图**：可复用站点 logo（`public/clover-logo.svg` 导出的 PNG），或使用工具相关截图；
4. 发布前用「预览」模式通读一遍，重点检查代码块换行和表格；
5. 发布后到 `发布计划.csv` 里把该行标记为已发布（可加一列备注链接）。

## 三、防「广告/低质」判定

- 每篇文章的推广位固定在文末「相关工具推荐」一段，正文不插入硬广；
- 正文以解决问题为主（报错原因、代码示例、操作步骤），工具只作为「在线尝试」的补充；
- 每篇外链控制在 1~2 个站内工具链接 + 1 个首页链接，不要堆链接；
- 不要在文章开头放链接，先给内容；
- 同一天不要连续发布同一工具的多篇文章，避免被 CSDN 判定为重复内容；
- 21 篇待补全文章补正文时，参考同关键词素材的 `desc` 扩展，控制字数在 800~1500 字。

## 四、内链与 SEO 策略

1. **文章内链**：`发布计划.csv` 里每篇都有「工具链接」，指向 clovertools.cn 对应工具页，让 CSDN 文章流量回流站点；
2. **同工具文章互链**：同一工具目录下的多篇文章发布后，可在文末互相推荐（例如「时间戳转换」系列 4 篇互链），提升 CSDN 站内关联度；
3. **站点收录配合**：README 已规划 Google/Bing/百度收录（sitemap 已配置），CSDN 文章被百度收录后，与站点本身形成关键词矩阵；
4. **复盘**：每周看一次 CSDN 后台数据（阅读量、收藏、评论），以及百度收录情况，把流量好的关键词补充进 `data/keywords.json`，继续扩写。
