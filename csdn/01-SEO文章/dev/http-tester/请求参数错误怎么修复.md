## 请求参数错误怎么修复？6种类型及防御性编程实践

前后端交互中，参数错误是最常见的接口问题之一。系统性地了解参数错误的类型、处理方式和防御性编程技巧，可以大幅提升应用的稳定性。

## 1. 参数类型错误

```
// 后端期望number，前端传了string "16"
fetch('/api/users', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ age: Number(ageInput.value) })
});
```

## 2. 必填参数缺失

```javascript
// 后端使用Joi/Zod等schema校验库
const schema = z.object({
  username: z.string().min(2, '用户名至少2个字符'),
  email: z.string().email('邮箱格式不正确'),
  age: z.number().min(0).max(150)
});

const result = schema.safeParse({ username, email, age });
if (!result.success) {
  console.error('参数校验失败:', result.error.issues);
}
```

## 3. 参数格式不符合要求

```javascript
// 日期格式：ISO 8601
const dateStr = new Date().toISOString();  // "2024-05-10T00:00:00.000Z"
```

## 4. 枚举值超出范围

```javascript
// ✅ 前端维护枚举常量
const STATUS = { PENDING: 'pending', APPROVED: 'approved', REJECTED: 'rejected' };
fetch('/api/update', {
  method: 'PUT',
  body: JSON.stringify({ status: STATUS.APPROVED })
});
```

## 5. 参数越界

```javascript
// 分页参数：page从1开始，size最大100
const page = Math.max(1, parseInt(req.query.page) || 1);
const size = Math.min(100, Math.max(1, parseInt(req.query.size) || 20));
```

## 6. JSON结构不匹配

```javascript
// ✅ 对照API文档构建请求体
const requestBody = {
  data: {
    user: {
      profile: {
        name: nameInput.value
      }
    }
  }
};
```

## 常见问题 FAQ

Q: 后端说"参数错误"但不告诉我是哪个参数，怎么办？
A: 可以先逐个参数测试，或使用抓包工具查看完整错误响应。

Q: 前端参数校验和后端校验都要做吗？
A: 前端校验提升用户体验，后端校验保证安全性。两者都要有。
