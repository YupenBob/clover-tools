## 正则表达式匹配不到内容怎么解决？5个真实案例

正则表达式写错后既不报错也不匹配。以下通过5个真实案例帮助你彻底搞懂。

## 案例一：转义字符写错

```javascript
const url = 'https://example.com/item/12345';
// ✅ 在正则中，/不需要转义，.才需要
const goodRegex = /https:\/\/example\.com\/item\/(\d+)/;
```

## 案例二：贪婪匹配导致捕获组为空

```javascript
const html = '<div>hello world</div><div>hi there</div>';

// ❌ 贪婪：.* 会匹配到最后一个</div>
html.match(/<div>(.*)<\/div>/)[1];  // "hello world</div><div>hi there"

// ✅ 非贪婪：.*? 匹配到第一个</div>就停止
html.match(/<div>(.*?)<\/div>/)[1];  // "hello world"
```

## 案例三：中文Unicode匹配问题

```javascript
const text = '张三和李四';

// ❌ 只匹配ASCII字母
/[a-zA-Z]+/.test(text);  // false

// ✅ 使用Unicode范围匹配中文
/[\u4e00-\ua5ff]+/.test(text);  // true
```

## 案例四：单词边界与中文

```
// \b 单词边界对中文无效
'欢迎访问clovertools在线工具站'.match(/\bclover\b/);  // null

// ✅ 使用前后断言
/(?<=^|[^a-zA-Z])clover(?=$|[^a-zA-Z])/.test('欢迎访问clovertools在线工具站');  // true
```

## 案例五：正则全局标志lastIndex问题

```javascript
const regex = /foo/g;
regex.test('foo foo foo');  // true, lastIndex=3
regex.test('foo foo foo');  // false, lastIndex=3已到末尾
regex.test('foo foo foo');  // true, lastIndex重置为0
```

## 常见问题 FAQ

Q: 为什么replace()只替换了第一个匹配？
A: 使用了不带g标志的正则。

Q: 正则性能很差怎么办？
A: 避免贪婪匹配.*改用非贪婪.*?；避免在字符类中使用.。
