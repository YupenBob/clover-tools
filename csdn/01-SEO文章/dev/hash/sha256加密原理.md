# SHA-256加密原理详解 - 密码存储、文件校验、代码示例

> 详解SHA-256哈希算法的工作原理、与MD5/SHA-1的区别、密码存储的正确方式，以及JavaScript代码实现。

## SHA-256的数学基础

SHA-256是SHA-2（Secure Hash Algorithm 2）家族中最著名的成员，由美国国家安全局（NSA）于2001年发布。它使用一系列位操作（逻辑运算、模加、移位）和常数初始化值，经过64轮迭代计算，将任意长度的输入消息转换为一个256位的哈希值。

## 算法流程概览

1. 消息预处理：将输入消息填充到512位的倍数，并在末尾添加原始长度信息
2. 分解为块：将预处理后的消息分解为512位（64字节）的数据块
3. 初始化哈希值：使用8个32位的初始常数（由前8个质数平方根的小数部分生成）
4. 64轮迭代压缩：对每个数据块进行64轮复杂的位运算，更新哈希值
5. 输出最终哈希：所有块处理完成后，输出8个32位字连接成的256位哈希值

## 核心运算函数

SHA-256使用六个主要的位运算函数：Ch(x,y,z) 选择函数、Maj(x,y,z) 多数函数、Σ0(x) 和 Σ1(x) 旋转移位组合、σ0(x) 和 σ1(x) 用于消息调度的小σ函数。

## 为什么SHA-256是安全的？

安全性来自：雪崩效应（输入改变一位，输出大约一半的位会改变，无法预测）、抗碰撞性（找到两个不同输入产生相同输出的成本极高）、单向性（从哈希值无法反推原始输入）、结构设计（64轮迭代和精心选择的常数确保没有已知的数学捷径）。

## SHA-256 vs 其他算法

与MD5（128位，已被破解）和SHA-1（160位，已有碰撞攻击）相比，SHA-256的安全性更高。与SHA-512（512位）相比，SHA-256在32位系统上效率更高，且目前没有已知的有效攻击。
