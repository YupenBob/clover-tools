## 为什么你的正则永远匹配不到？5个真实案例帮你彻底搞懂

正则表达式写完后测试不通过，既不报错也不匹配。以下通过5个真实案例帮助你彻底搞懂。

## 案例一：字符边界与单词边界

```javascript
const url = 'https://clovertools.com/path';
// \b对特殊字符.不生效
const goodRegex = /clovertools\.com/;
goodRegex.test(url);  // true
```

## 案例二：量词的贪婪与非贪婪

```javascript
const text2 = 'hello world hello python';
text2.match(/hello.*world/);  // ["hello world hello python"]
text2.match(/hello.*?world/);  // ["hello world"]
```

## 案例三：中文字符的匹配

```
/[\u4e00-\ua5ff]+/.test('张三');  // true
/\p{Han}+/u.test('张三');  // true（ES2018+）
```

## 案例四：正则表达式对象的复用问题

```javascript
const regex = /foo/g;
regex.test('foo foo foo');  // true
regex.test('foo foo foo');  // false（lastIndex已到末尾）

// 解决方案：不用/g
/ /.test('foo foo foo');
```

## 常见问题 FAQ

Q: 为什么正则测试工具能匹配，但JS代码中不匹配？
A: 检查flags是否一致，特别是全局标志g的使用。

Q: 正则性能很差怎么处理？
A: 避免贪婪量词.*改为非贪婪.*?；避免在字符类中使用.。
