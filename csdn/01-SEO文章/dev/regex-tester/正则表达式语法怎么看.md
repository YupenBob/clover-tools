# 正则表达式语法怎么看？新手入门完全指南

> 正则表达式是程序员必备技能之一。本文用实例讲解正则的基本语法：字符类、量词、锚点、分组、替换，让新手快速入门。

## 正则基础语法

### 字符类

```
.  # 任意字符
\d  # 数字 [0-9]
\w  # 字母数字下划线 [a-zA-Z0-9_]
\s  # 空白字符
[abc]  # a或b或c
[^abc]  # 除了a/b/c
[a-z]  # a到z
```

### 量词

```
*  # 0次或多次
+  # 1次或多次
?  # 0次或1次
{n}  # 正好n次
{n,}  # n次以上
{n,m}  # n到m次
```

### 锚点

```
^  # 字符串开头
$  # 字符串结尾
\b  # 单词边界
```

### 分组

```
(abc)  # 捕获组
(?:abc)  # 非捕获组
(?=abc)  # 正向先行断言
(?!abc)  # 负向先行断言
```

## 实例讲解

```bash
# 匹配手机号
^1[3-9]\d{9}$  # 中国手机号

# 匹配邮箱
^[\w.-]+@[\w.-]+\.\w+$

# 匹配日期
^\d{4}-\d{2}-\d{2}$  # 2024-01-01
```
