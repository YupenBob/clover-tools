# 正则全局匹配只匹配到第一个？原因与正确用法详解

> 正则表达式用exec或match全局匹配时只返回第一个结果，是新手常见痛点。本文解释JavaScript/Python/Go中正确的全局匹配方式，以及replace配合回调函数的强大用法。

## 为什么全局匹配只返回第一个？

这是正则表达式的经典陷阱。JavaScript中：/a/g.exec(str)每次调用从lastIndex位置开始搜索，全局标志不会自动重置。

## 正确做法

### JavaScript：用match配合while循环

```javascript
let match;
const results = [];
while((match = /pattern/g.exec(str)) !== null) {
  results.push(match[0]);
}
```

### Python：re.findall

```
import re
results = re.findall(r"pattern", text)
```

## replace配合回调函数

```
str.replace(/\d+/g, (match) => parseInt(match) * 2)
```
