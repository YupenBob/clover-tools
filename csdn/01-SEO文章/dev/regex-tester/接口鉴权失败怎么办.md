# 接口鉴权失败怎么办？JWT/Token/API-Key认证失败排查与修复

> 接口返回401/403鉴权失败是常见问题。本文详解常见鉴权方式（JWT/Bearer Token/API-Key/OAuth2）的正确用法，以及常见失败原因和修复步骤。

## 鉴权失败的HTTP状态码

- 401 Unauthorized：未提供凭据或凭据无效
- 403 Forbidden：凭据有效但权限不足

## 常见鉴权方式与正确用法

### 1. Bearer Token (JWT)

```
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

注意：Bearer和Token之间有一个空格，不是两个。

### 2. API-Key

```
Authorization: ApiKey your_api_key_here
// 或
X-API-Key: your_api_key_here
```

### 3. Basic Auth

```
Authorization: Basic dXNlcm5hbWU6cGFzc3dvcmQ=
```

## 5步排查流程

1. 检查Token是否过期（JWT exp字段）
2. 检查Authorization header格式是否正确
3. 检查Token是否被URLencode破坏了（如&符号）
4. 确认API Key/Password没有多余空格
5. 确认接口需要的鉴权方式与发送的一致
