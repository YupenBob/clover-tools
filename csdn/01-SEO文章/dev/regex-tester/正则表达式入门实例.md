## 正则表达式入门与实例完全指南

正则表达式（Regular Expression）是处理字符串的强大工具。本文从基础语法到实际案例，帮助你从零掌握正则表达式。

## 字符类与转义

```
[abc]     // 匹配a、b或c
[^abc]    // 匹配除了a、b、c以外的任意字符
[a-z]     // 匹配小写字母
\d       // 等价于[0-9]，数字
\w       // 等价于[a-zA-Z0-9_]，单词字符
\s       // 空白字符
```

## 量词

```
a*        // 匹配0个或多个a
a+        // 匹配1个或多个a
a?        // 匹配0个或1个a
a{3}      // 恰好匹配3个a
a{3,5}    // 匹配3到5个a
a*?       // 非贪婪匹配
```

## 常见实战案例

```
// 手机号（中国大陆）
/^1[3-9]\d{9}$/

// 邮箱
/^[\w.-]+@[\w.-]+\.\w+$/

// 密码强度（至少8位，包含大小写字母和数字）
/^(?=.*[a-z])(?=.*[A-Z])(?=.*\d)[a-zA-Z\d]{8,}$/
```

## 常见问题 FAQ

Q: 为什么正则中\d和普通d不一样？
A: \d是元字符，代表数字0-9。

Q: 什么是正则表达式的"灾难性回溯"？
A: 贪婪量词可能导致指数级回溯。改用非贪婪或优化正则结构。
