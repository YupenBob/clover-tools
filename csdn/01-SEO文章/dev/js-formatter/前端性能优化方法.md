## 缓存策略

```
// Service Worker缓存
self.addEventListener('fetch', (event) => {
  event.respondWith(
    caches.match(event.request).then(response => {
      return response || fetch(event.request);
    })
  );
});

// HTTP缓存头
Cache-Control: max-age=31536000, immutable
```

## 关键渲染路径

```
1. 构建DOM树
2. 构建CSSOM树
3. Layout（计算位置尺寸）
4. Paint（绘制像素）
5. Composite（合成层）

优化目标：减少Layout和Paint次数
```
