## 为什么JSON需要优化？

JSON（JavaScript Object Notation）已经成为现代Web开发中最常用的数据交换格式。但在实际项目中，JSON文件往往体积过大，影响传输效率和加载速度。掌握一些实用的JSON格式优化技巧，可以显著提升应用性能。

## 1. 移除不必要的空格和换行

在开发和调试阶段，我们通常会格式化JSON以便于阅读。但在生产环境中，这些空格和换行完全是冗余的。例如一个1MB的JSON文件，格式化后可能变成2MB。移除所有空白字符后，文件体积通常可以减少20%~30%。

## 2. 压缩重复的键名

如果同一个键名在JSON中多次出现，可以考虑将重复的键提取为变量，或者在业务层面使用枚举值代替字符串。例如将 "type": "user" 替换为 "type": 1（其中1代表user类型），可以有效减少体积。

## 3. 启用Gzip或Brotli压缩

在HTTP传输层面，启用服务器端的Gzip或Brotli压缩是最有效的优化手段。通常可以将JSON文件压缩到原始大小的10%~30%。Nginx、Apache等主流服务器都支持开箱即用的压缩配置。

## 4. 使用更短的分隔符

标准的JSON使用冒号（:）和逗号（,）作为分隔符。在一些特殊场景下，可以使用自定义格式来进一步压缩，但这会牺牲可读性和通用性，适合内部系统之间的高速通信。

## 5. 分页加载与增量更新

对于大型数据集，不要一次性加载全部数据。采用分页（Pagination）或增量更新（Delta Update）策略，每次只请求必要的数据，既节省带宽又提升响应速度。
