# Base64编码原理是什么？为什么用它？有什么优缺点？

> Base64是开发中常用的编码方式，但很多人只知其然不知其所以然。本文从原理层面详解Base64的编码过程、用途、以及优缺点。

## Base64是什么

Base64是一种将二进制数据编码为64个可打印ASCII字符的方法。用途是把任意二进制数据转成文本字符串，方便在JSON、URL、HTML中传输。

## 编码原理

每3个字节（24bits）分成4组，每组6bits，对应0-63的索引，查Base64字符表：

```
A-Z (0-25)
a-z (26-51)
0-9 (52-61)
+/=
```

不足3字节的用= padding补齐。

## 为什么发明Base64

早期某些传输通道只支持文本，不支持二进制。比如HTTP头、XML、JSON、MIME邮件等。Base64解决了二进制数据在这些通道中的传输问题。

## 优缺点

### 优点

- 让二进制数据变成纯文本，安全传输
- 解决特殊字符问题（如二进制中的控制字符）

### 缺点

- 体积增加约33%
- 编解码有CPU开销
- 不适合大量数据传输
