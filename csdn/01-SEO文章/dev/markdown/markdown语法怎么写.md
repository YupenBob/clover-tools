# Markdown语法怎么写？常用语法完整指南

> Markdown是开发者写文档最常用的格式。本文整理最常用的Markdown语法：标题、链接、图片、代码块、表格、任务列表，附带实例和快捷键。

## 基础语法

```bash
# 一级标题
## 二级标题
### 三级标题

**粗体**  __粗体__
*斜体*   _斜体_
~~删除线~~

[链接文字](https://example.com)
![图片alt](image.jpg)
```

## 代码块

```javascript
\`\`\`javascript
const hello = () => console.log("Hello");
\`\`\`

行内代码：`const x = 1;`
```

## 列表

```
- 无序列表项
- 另一个项
  - 嵌套列表（缩进2个空格）

1. 有序列表第一项
2. 第二项
3. 第三项
```

## 表格

```
| 列1 | 列2 | 列3 |
|---|---|---|
| A | B | C |
| 1 | 2 | 3 |
```

## 任务列表

```
- [x] 已完成项
- [ ] 未完成项
- [ ] 待办事项
```

## 引用和分隔线

```
> 引用文字

---（分隔线）
```
