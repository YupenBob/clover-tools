# JSON数据对比技巧 - 深度diff算法、RFC 6902 Patch、实战代码

> 详解JSON对比的难点（顺序无关、深层嵌套、数组），以及Deep Diff、JSON Patch等常用算法和工具。

## JSON数据对比的使用场景

在日常开发中，我们经常需要比较两个JSON对象的差异，例如：代码上线前后的数据变化对比、API响应差异分析、数据库记录更新对比、配置文件变更检测等。手动对比JSON既繁琐又容易出错，自动化对比工具可以大大提升效率。

## JSON对比的核心逻辑

1. 键的差异：左边有而右边没有的键（删除项）、右边有而左边没有的键（新增项）
2. 值的差异：同一键在不同对象中值不同（修改项）
3. 类型差异：同一键在两个对象中类型不一致（如字符串改为数字）
4. 嵌套结构：递归比较深层嵌套的对象和数组

## 数组的对比策略

- 按位置比较：逐个比较相同索引位置的元素，适合顺序有意义的数组
- 按内容匹配：忽略顺序，尝试将两边元素一一配对，适合无序集合

## 差异展示格式

```
{
  "added": { "key3": "value3" },
  "removed": { "key1": "value1" },
  "changed": {
    "key2": { "old": "value2a", "new": "value2b" }
  }
}
```

## 深度对比与浅对比

浅对比只比较对象的第一层键值，深对比会递归到所有嵌套层级。对于大型JSON对象，深对比可能消耗较多计算资源，可以考虑只比较部分路径或设置最大递归深度。
