# Cron表达式详解 - 每字段含义、常用示例、避坑指南

> 详解Linux Cron表达式的5个字段、特殊字符、常见错误和在线测试方法。让你从零掌握定时任务配置。

## Cron表达式是什么？

Cron是Unix/Linux系统中基于时间的任务调度器，使用cron表达式来定义精确的执行时间。cron表达式由5或6个字段组成，每个字段表示一个时间单位，通过空格分隔。

```
┌─────────────── 分钟 (0-59)
│ ┌───────────── 小时 (0-23)
│ │ ┌─────────── 日 (1-31)
│ │ │ ┌───────── 月 (1-12)
│ │ │ │ ┌─────── 星期 (0-7, 0和7都是周日)
│ │ │ │ │
* * * * *
```

## 字段取值说明

- *（星号）：匹配该字段的所有值。例如分钟字段的 * 表示每分钟。
- ，（逗号）：列举多个值。如 1,3,5 表示1点、3点、5点。
- -（减号）：表示范围。如 1-5 表示1到5点。
- /（斜杠）：表示步长。如 */5 表示每5个单位执行一次。
- ?（问号）：用于日或星期字段，表示任意值（避免冲突）。

## 常用表达式示例

```
0 * * * *          # 每小时整点执行
0 9 * * 1-5        # 每周一到周五早上9点执行
*/15 * * * *       # 每15分钟执行一次
0 0 1 * *          # 每月1号午夜执行
0 2 * * *          # 每天凌晨2点执行
30 4 1,15 * *      # 每月1号和15号凌晨4:30执行
```

## 6字段格式（含秒）

部分系统（如Spring Framework、Quartz）使用6字段格式，在标准5字段前增加秒字段。例如 0 0 9 * * * 表示每天9点整执行。

## 时区注意事项

Cron表达式默认使用系统时区。如果服务器在UTC时区，但你的业务在北京时间（UTC+8），需要特别注意。建议在配置中明确指定时区，避免夏令时切换等边界问题。
