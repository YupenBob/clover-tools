# 时间戳转换工具怎么用？Unix时间戳与日期互转完整教程

> 时间戳是后端开发中的常见数据类型。本文讲解Unix时间戳的概念、Python/JavaScript/Go中的时间戳互转，以及时区处理注意事项。

## 什么是Unix时间戳

Unix时间戳是从1970年1月1日00:00:00 UTC到现在的秒数。例如：1700000000表示2023-11-14 20:53:20 UTC。

## 各语言时间戳互转

### JavaScript

```javascript
// 日期转时间戳（毫秒）
const ts = Date.now();
const date = new Date(ts);

// 时间戳转日期
const d = new Date(1700000000 * 1000);
console.log(d.toISOString());
```

### Python

```
import time
from datetime import datetime

# 当前时间戳（秒）
ts = int(time.time())

# 时间戳转日期
d = datetime.fromtimestamp(ts)

# 日期转时间戳
ts = int(d.timestamp())
```

## 时区注意事项

- 后端存储尽量用UTC，转换时注意时区
- JavaScript Date.now()返回的是本地时间戳（毫秒）
- JSON传递时间用ISO 8601格式比时间戳更明确
