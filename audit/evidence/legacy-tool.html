工具使用说明

当接口返回一大段 JSON，真正麻烦的通常不是“看不懂”，而是无法确认它是否完整、字段类型是否正确。通过格式化时的语法校验，可以把括号、引号和逗号问题定位到可修复的位置。

01 使用步骤

  1. 将接口响应或配置片段粘贴到输入框。
  2. 选择缩进宽度，点击格式化；若有语法错误，按提示回到对应行检查。
  3. 需要传输时切换到压缩结果，并复制或下载处理后的文本。

03 原理与边界

  • 标准 JSON 只允许双引号包围键名和字符串值，不接受单引号。
  • 格式化只改变空白，不会替你修正字段名、数值类型或业务含义。
  • 压缩适合网络传输，开发排错应保留格式化版本。

常见误区

  • 把 JavaScript 对象直接当作 JSON：undefined、函数和注释都不是标准 JSON。
  • 看到“成功格式化”就认为业务数据正确；语法正确不代表字段符合接口契约。
  • 对包含密码或令牌的内容截图、复制到第三方服务。

04 常见问题

为什么单引号会报错？

JSON 规范要求字符串使用双引号。单引号属于 JavaScript 写法，需先转换后再校验。

格式化会上传我的数据吗？

本工具在浏览器中解析输入，不需要向服务器发送文本；仍建议在公共电脑上使用后及时清空输入。
